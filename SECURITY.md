# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/liquidlm/typescript-sdk/security/advisories/new).
Do not open public issues for security reports. If the advisory channel is
unavailable, use `support@liquidlm.com` with "Security" in the subject.

Do not put credentials, signed URLs or customer content in reports or
reproduction logs. Use synthetic data. SDK exceptions and debug logs should
contain only the metadata needed to diagnose a failure.

Supported versions: fixes land on the latest alpha prerelease; older
prereleases are not patched individually.
